Check by hand

  • chrome://version: says Iris / jegly; profile path ends in .config/iris.
  • chrome://settings/search: DuckDuckGo default. chrome://settings/security: secure DNS on, Quad9, 15 providers in the list; HTTPS-Only on.
  • chrome://settings/cookies: third-party cookies blocked. chrome://settings/content/javascriptJit: blocked by default.
  • chrome://gpu: pages render; WebGPU disabled; video decode software only.
  • TLS 1.3 minimum: https://tls-v1-2.badssl.com:1012/ must FAIL; https://example.com must load.
  • HTTPS-Only: http://neverssl.com shows a warning first.
  • Ads: on a news site, Page Info (padlock) has an "Ads" entry you can switch to Allow.
  • PDF: a web PDF downloads/opens externally instead of inside the browser.
  • Printing: the menu has no Print entry and Ctrl+P does nothing.
  • Cookie encryption (Linux): chrome://version command line has no --password-store=basic; after a restart you stay logged in (the key comes from the desktop keyring / Secret portal).
  • ECH (encrypted site name): https://tls-ech.dev says "You are using ECH"; https://defo.ie/ech-check.php shows SSL_ECH_STATUS success.
  • No first-run welcome page on a fresh profile. New tab page is local (no network request in DevTools).
