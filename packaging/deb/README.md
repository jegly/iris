# Iris .deb packaging — use Chromium's own Linux installer (plan revised 2026-09-26)

## Why not hand-roll it
A working Chromium tree is far more than the `chrome` binary: `*.pak`, `icudtl.dat`, V8 snapshot blobs,
`libEGL.so`/`libGLESv2.so`, `libvk_swiftshader.so` + ICD json, `locales/`, `chrome-sandbox`,
`chrome_crashpad_handler`, `xdg-*` helpers, desktop file, icons, AppArmor profile, maintainer scripts.
Chromium's installer (`chrome/installer/linux/`) already knows the exact list, computes Depends: with
`dpkg-shlibdeps`, and does the security-critical parts correctly:
- installs `chrome-sandbox` **setuid 4755** (`installer.py`: `SANDBOX = 0o4755`) -> real Chromium sandbox on
  systems WITHOUT unprivileged user namespaces (jegly's box) -> no `--no-sandbox`.
- installs an AppArmor profile (`common/apparmor.template`) that permits `userns` for the browser, needed
  for the namespace sandbox on stock Ubuntu 23.10+ (restricted unprivileged userns). flags=(unconfined):
  it grants userns only, it does not confine the browser.
Host tools needed are present: fakeroot, dpkg-deb, dpkg-shlibdeps.

## Build (after out/Linux/chrome is built)
```
cd ~/Documents/chromium/src
autoninja -C out/Linux chrome/installer/linux:stable_deb     # confirm exact name: gn ls out/Linux //chrome/installer/linux:*
# -> out/Linux/<package>-stable_<version>-1_amd64.deb
```

## Wrapper / launcher
The package installs `common/wrapper` as the `/usr/bin/<package>` entry point. Once the STAGED patches are
applied, the hardening switches + WebGPU-off are compiled into the binary, so the wrapper no longer has to
carry them. Plan: keep Chromium's wrapper and add the config-integrity check call from
`../launcher/iris-launcher` (+ ship `iris-config.manifest`, generated by `../verify/iris-gen-config-manifest.sh`).

## Release
`../verify/iris-gen-hashes.sh <deb>` -> SHA256SUMS/SHA512SUMS, then GPG-sign (see `../verify/README.md`).

## Snap
Build the snap FROM this .deb (snapcraft `plugin: dump` accepts a `.deb` source) so both packages share the
same, correct file list. See `../snap/snapcraft.yaml` (its current `organize:` only copies the chrome binary —
superseded by this approach).
